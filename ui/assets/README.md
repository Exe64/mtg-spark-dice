# Fonts

Barlow Condensed ExtraBold and SemiBold, from google/fonts (`ofl/barlowcondensed`), SIL Open Font License 1.1 (`OFL.txt`).

Modified with `strip_gpos.py`: the GPOS table tag is renamed so LVGL 9.2.2's tiny_ttf / stb_truetype does not read
past the font buffer (see the script header). Outlines and metrics are unchanged.

# Defeat mark

`dead.svg`, supplied by the project owner (2026-11-12); resembles the Magic black mana symbol; Wizards materials are allowed by the owner (see PRODUCT.md, Brand Commitments). Converted with `python3 svg2a8.py dead.svg ../skull_a8.c ui_skull_a8 160 2` into a 160×160 A8 alpha mask that the UI tints with the seat hue.

# Light masks and line icons (luminous theme)

`../fx_a8.c` is generated by `python3 glow_gen.py ../fx_a8.c`: a glowing ring (128×128), a ray (32×128) and eight 40×40 line icons (settings, players, resume, game type, undo, turn, wifi, room), all A8 alpha masks that `ui/fx.c` tints at draw time. Every mask is computed by the script; the icons are drawn for this project from plain strokes, no external source.

# Logo masks

`../logo_a8.c` is generated by `python3 logo2a8.py ../logo_a8.c` from `logo.svg` (owner-approved, drawn by `logo_gen.py`): two A8 masks cropped to the drawing, 237×195 for the boot screen and 72×60 for the home, tinted with the theme ink. The script renders through GdkPixbuf and librsvg (PyGObject) because the logo uses blurs, masks and text.

# Product name (wordmark)

`../wordmark_a8.c` is generated by `python3 wordmark2a8.py "Dice Spark" "licensed/Original Motion.ttf" ../wordmark_a8.c`: the product name set in Original Motion by Cat.B (https://www.dafont.com/original-motion.font), chosen by the owner on 2026-11-13, as two A8 masks (boot screen and home). The font is free for personal use only: the TTF is not committed (`licensed/` is git-ignored; download it there to regenerate) and is not embedded in the firmware. Only the rendered name is in the repository. A commercial or distributed product would need a licence from the author or another typeface.

# Home icons

`../home_icons_a8.c` is generated by `python3 icons2a8.py ../home_icons_a8.c` from `icons/` (settings.svg, update.png, host.png, join.png), supplied by the owner on 2026-11-13: four A8 masks tinted by the UI. `settings.svg` comes from Icons8 (file name given by the owner: "icons8-paramètres"); the three PNG are in the same style, source not stated by the owner. Icons8's free licence asks for a link to icons8.com wherever the icons are published: to be confirmed and added by the owner before any distribution.

# Marker icons

Same generator, same folder: `icons/energy.png`, `rad.png`, `day.png`, `night.png`, supplied by the owner on 2026-11-13 (source not stated), become `ui_marker_icons_a8[]` (28×28) for the markers panel. The other markers keep a 3-letter label until their icon is supplied.
